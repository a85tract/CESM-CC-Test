## The blocker: the summary format

Neither file can be evaluated today. `make_manifest.py` reads the engine's schema-1 summary
(`schema: 1`, a `units` list of verdict objects, the file `recast run --summary` writes).
The case's `run_port.py` writes something else: one merged file keyed by unit,
`{unit: {verdict: "<string>", stopped, kernels}}`, where the verdict is the engine's
printed line (`[ok ] verifier differential.tolerance toleranced: ...`). It is merged across
runs, so a run of one unit leaves the others' verdicts in place. Nothing in it can be read
as a gate, a confidence or a metric without parsing prose, and `make_manifest.py` does not
parse prose.

To become evaluable, the case has to commit, per recording, the summary `recast run
--summary` writes, and name it in `case.summary` here. The criterion does not change.

## Three units that fail the gate, and stay gated

| unit | day 1 | day 15 | day 1, jit off |
|---|---|---|---|
| `mlfluxprofilesolutionmod` | 67175 ULP | 4346 ULP | exact |
| `mllongwaveradiationmod` | 5792 ULP | 3584 ULP | exact |
| `mlsoilfluxesmod` | 2399 ULP | 1722 ULP | exact |

Worst dominant element against the 32-ULP gate, under jit with XLA's default passes. Day 1
from `output/run_port.regate2.log`, day 15 from `output/port.day15/summary.json`. The case
README attributes the residual to XLA fusion. The verifier's own verdict line calls it
"where a translation defect shows, not where conditioning does".

These are neither `ungated` nor waived. `ungated` is for a unit the gate cannot judge; these
were judged. A waiver needs a measurement showing the residual is conditioning of the
reference, and the verifier's measurement says the opposite. So the three stay gated, and
once the summary is readable both cases will read FAIL, until the kernels are fixed or the
maintainer carves the units out in these files with a written reason. The criterion is not
bent to fit the result.

The other units: on day 1, 12 of 15 pass the gate under jit; on day 15, 11 of the 14 the
recording reaches (case README, and `output/port.day15/summary.json`).
